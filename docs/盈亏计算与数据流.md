# 盈亏计算 · 通知 · 前后端交易数据流

> 梳理项目里每一处「盈亏怎么算、通知发什么、前后端怎么展示」。
> 代码路径:vnpy-domestic(RolloverCtaEngine 实盘引擎)+ web-backend + web-frontend。

---

## 一、盈亏计算(从成交到账户,逐层)

### 1. 滑点 slippage
- 位置:`RolloverCtaEngine.py` `process_trade_event`
- 多头成交:`slippage = 成交价 − 挂单价`
- 空头成交:`slippage = 挂单价 − 成交价`
- 正值 = 不利滑点。写 `trades.slippage`,前端成交表展示。

### 2. 平仓盈亏 settle_close(两口径)
- 位置:`trader/position_lots.py` `settle_close(lots, ..., prev_settle, ...)`
- **开仓价口径(累计盈亏)**:`(平仓价 − 开仓价) × 手数 × 方向乘数`
  → 写 `trade_rounds.pnl`(交易绩效统计用)
- **逐日盯市口径(今日已实现)**:隔日仓 `(平仓价 − 昨结算价)`、当日仓 `(平仓价 − 开仓价)`
  → 累加 `_today_realized_pl` / `strategy_cumulative_pl`
- 方向乘数:卖平多 = 1,买平空 = −1
- 昨结算价来源:`settlements` 表(启动时从交易所日线拉取,按 `(account, symbol, trading_day)` 取平仓日之前最近一条);表里没有时回退 CTP 持仓成本价 `pos.price`(纯隔日仓)
- 点·手 × 合约乘数 `size` = 元

### 3. 策略累计盈亏 strategy_cumulative_pl
- 平仓时累加「逐日盯市 pl × size」
- 用于:平仓通知"累计盈亏"、每日汇总"已实现"、`strategy_intraday.realized_pl`、`daily_pnl.cumulative_pl`

### 4. 今日已实现 _today_realized_pl
- 平仓时累加「逐日盯市 pl × size」,跨交易日归零(`_write_account_positions` 里检测交易日变化)
- 写 `account_intraday_pnl.realized_pl`

### 5. 账户浮动盈亏 floating_pl
- `_write_account_positions` 累加 CTP 持仓盈亏 `pos.pnl`
- CTP 逐日盯市口径:隔日仓 = 最新价 − 昨结算价,当日仓 = 最新价 − 开仓价
- 写 `account_intraday_pnl.floating_pl`

### 6. 账户日内盈亏 AccountIntradayPnl(15 分钟一条)
- `realized_pl`(4)+ `floating_pl`(5)+ `balance`(CTP 余额)

### 7. 策略日内快照 StrategyIntraday(15 分钟)
- `realized_pl = strategy_cumulative_pl`
- `floating_pl = (最新价 − 持仓均价) × pos × size`(引擎自算)
- `equity = realized + floating`

### 8. trade_rounds(平仓配对,交易绩效)
- `entry_price` / `exit_price` / `pnl = (平仓价 − 开仓价) × size`(开仓价口径)/ `holding_seconds`
- 前端绩效:胜率、盈亏比、平均持仓、收益率

## 二、通知发送(飞书/钉钉,全走 notify)

| 触发 | 时机 | 内容 |
|------|------|------|
| 🟢 开仓 | on_trade 开仓 | 合约/方向/价格/数量/最新持仓 |
| 🔴 平仓 | on_trade 平仓 | 平仓价/数量 + **对应开仓批次**(每批:手数/开仓价/开仓时间/持有时间/该批盈亏) + 本次盈亏(逐日盯市 pl_amount)+ 累计盈亏(strategy_cumulative_pl) |
| ⚠️ 未成交 | on_order NOTTRADED | 开仓单/平仓单 + 方向/价格/数量;平仓单加「预估盈亏」=(挂单价 − FIFO队头成本)×数量×方向×size |
| ❌ 拒单 / 🟡 撤销 | on_order | 合约/方向/价格/数量 |
| 🔄 换月汇总 | 启动时 | 已换月 / 持仓不为零被阻塞 |
| 📊 账户报告 | 每 7 分钟 | 动态权益、可用、当日订单统计、活跃挂单、持仓、CPU/内存/磁盘/运行时长 |
| 📊 当日盈亏汇总 | 收盘退出 | 逐策略「已实现」(逐日盯市)+ 剩余持仓 + 合计已实现 |
| ⚠️/🟢 CTP 断连 | 120s 无活动/恢复 | 告警 / 恢复 |

## 三、前后端交易数据流

### 写库(MonitorWriter,队列+后台线程,异步不阻塞交易)
- `orders`:每状态一行(含 `queue_delay_ms` 入队延迟、`cancel_delay_ms` 撤单延迟)
- `trades`:每成交一行(含 `slippage` 滑点)
- `positions` / `account_positions`:策略持仓 / CTP 账户持仓
- `account_intraday_pnl`:账户日内盈亏(15 分钟)
- `strategy_status`(3 秒)/ `strategy_intraday`(15 分钟)
- `trade_rounds`:平仓配对;`daily_pnl`:每日盈亏;`logs`/`klines`/`contracts`

### 后端 web-backend
- REST(api.py):`/orders` `/trades` `/positions` `/account-positions` `/account-intraday-pnl`
  `/daily_pnl` `/stats/summary` `/klines` `/logs` `/contract` —— `_to_dict` 自动序列化 ORM 全列
- WS(ws.py,3 秒):增量推 账户资金/账户持仓/策略状态/系统指标/trade_rounds 快照

### 前端 web-frontend
- Dashboard:账户卡(权益/可用)、净值曲线、系统指标
- Orders 页:活跃挂单、全部委托(含入队/撤单延迟)、每日挂撤单频次
- StrategyDetail 页:合约信息、K 线、持仓、成交(含滑点)、委托(含入队/撤单延迟)、
  净值曲线、回撤、每日盈亏、绩效统计(胜率/盈亏比/平均持仓/收益率)

---

## 核心口径一句话

账户层(权益/浮动/今日已实现)走 **CTP 逐日盯市口径**;
交易绩效层(trade_rounds 胜率/盈亏比)走 **开仓价累计口径**;
两者在 `account_intraday_pnl` 表里分开存:`realized_pl`(逐日盯市)+ `floating_pl`(CTP pos.pnl)。
